# League of Legends Match Predictor 🏆🎮

This project is part of the **IBM Introduction to Neural Networks and PyTorch** course final project. The goal is to build a **logistic regression model** using **PyTorch** to predict the outcome of **League of Legends** matches based on in-game statistics. The project involves **data preprocessing, model training, optimization, evaluation, and visualization**.

---

## 📌 **Project Overview**
This project covers:
- **Data Loading & Preprocessing** (Downloading dataset, cleaning, feature scaling)
- **Model Implementation** (Logistic regression with PyTorch)
- **Training & Optimization** (SGD, L2 regularization, learning rate tuning)
- **Evaluation & Interpretation** (Accuracy, confusion matrix, ROC curve, AUC)
- **Feature Importance Analysis** (Impact of features on predictions)
- **Model Saving & Loading** (Persistence for deployment)
